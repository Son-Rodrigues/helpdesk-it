# 🖥️ HelpDesk IT

Sistema de Help Desk / Service Desk desenvolvido para simular uma central de atendimento de suporte técnico.

> 🚧 Projeto em desenvolvimento — esta é a primeira versão do sistema.

---

## 📌 Sobre o projeto

O **HelpDesk IT** é um projeto de portfólio desenvolvido para simular o funcionamento de uma central de suporte técnico.

A proposta é criar uma aplicação onde seja possível registrar, acompanhar e solucionar chamados de usuários, simulando situações comuns encontradas no dia a dia de uma equipe de Help Desk / Service Desk.

O projeto também tem como objetivo colocar em prática conceitos de desenvolvimento web, organização de código, controle de versão e processos de suporte técnico.

## 📚 Conceitos de Help Desk aplicados

Durante o desenvolvimento serão trabalhados conceitos relacionados a:

### Atendimento

Registro e acompanhamento das solicitações dos usuários.

### Incidentes

Identificação e tratamento de problemas que impedem ou prejudicam o funcionamento de um serviço.

### Prioridade

Classificação dos chamados de acordo com sua urgência e impacto.

### Status

Os chamados poderão passar por diferentes etapas:

```text
Aberto
   ↓
Em atendimento
   ↓
Pendente
   ↓
Resolvido
   ↓
Fechado
```

### SLA

O projeto utilizará o conceito de **Service Level Agreement (SLA)** para representar os prazos de atendimento e resolução dos chamados.
